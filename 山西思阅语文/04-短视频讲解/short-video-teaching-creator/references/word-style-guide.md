# Word Style Guide

Use this as the default house style for short-video teaching shooting scripts.

## Purpose

The Word file is a shooting script.

It should:

- be directly speakable
- keep editing friction low
- align with the slide sequence
- make trims and clip cuts easy

## Page Setup

- paper: default Word page or A4
- margins:
  - top `0.7 in`
  - bottom `0.7 in`
  - left `0.8 in`
  - right `0.8 in`
- body line spacing: about `1.25`

## Fonts

- Chinese body font: `Songti SC` or another readable serif Chinese font already available
- Latin font: `Arial`

Keep the font system simple and consistent.

## Title Block

Main title:

- center aligned
- `20 pt`
- bold
- dark blue `#1F4E79`

Subtitle:

- center aligned
- `11 pt`
- gray `#666666`
- usually: source | usage | paired PPT

Example:

```text
《心中有尺》心理活动补写题短视频拍摄脚本
省适应卷第12题第一问｜可直接口播｜配套PPT同步
```

## Section Heads

Use numbered major sections such as:

```text
1. 标题
2. 开场考情
3. 先把题做一遍
4. 第一层：从情节找原因
```

Format:

- `15 pt`
- bold
- red `#C0504D`
- about `10 pt` before
- about `4 pt` after

## Body Paragraphs

Format:

- `12.5 pt`
- black
- one main idea per paragraph
- `6 pt` after

Writing pattern:

- say the judgment first
- explain immediately after
- keep paragraphs short
- isolate key lines for emphasis

## Slide Cue Lines

Use only in the Word script, not in the PPT footer.

Format:

- `10.5 pt`
- italic
- gray `#5A5A5A`

Example:

```text
【画面提示】对应PPT第3页，可按本段关键词上屏。
```

## Fixed Script Skeleton

Use this order by default:

1. title
2. exam-context opening
3. solve the question first
4. reasoning layer 1
5. reasoning layer 2
6. reasoning layer 3
7. reveal scoring logic
8. show the full answer
9. summarize the method

## Quality Bar

The Word script passes when:

- it can be read out loud smoothly
- each section has a distinct job
- the opening establishes value fast
- the ending leaves a reusable method
- the slide cues line up with the PPT sequence
