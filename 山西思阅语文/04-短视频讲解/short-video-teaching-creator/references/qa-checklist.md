# QA Checklist

Run this before final delivery and after major revisions.

## Source Accuracy

- original question matches the source file
- official answer is read correctly
- scoring points are not invented
- any inferred teaching point is clearly grounded in the source

## Script Quality

- script can be spoken naturally
- opening quickly explains why the question matters
- low-score trap is explicit
- explanation has a clear progression
- full answer matches the scoring logic
- ending leaves a reusable method

## PPT Quality

- top labels are readable
- titles are large enough
- source screenshot is legible
- no unnecessary footer text remains
- there is enough whitespace
- no text overflow or cramped blocks
- contrast is strong enough for recording

## Alignment

- Word section sequence matches the PPT sequence
- keywords are consistent across both files
- answer wording is aligned across both files

## Revision Discipline

When the user asks for visual cleanup:

- keep the content spine stable
- change layout, scale, contrast, or density first
- only rewrite the teaching logic if the feedback reveals a content issue
