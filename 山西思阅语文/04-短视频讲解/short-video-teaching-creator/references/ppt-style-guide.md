# PPT Style Guide

Use this as the default house style for short-video teaching slide decks.

## Core Goal

The PPT is on-screen teaching support.

It must:

- read clearly during recording
- support the speaking rhythm
- make key logic visible fast
- avoid small decorative clutter

## Base Spec

- aspect ratio: `16:9`
- use case: recording, projection, teaching clips
- one core teaching objective per slide

## Typography

- Chinese font: `Microsoft YaHei` or another clear sans-serif Chinese font already available
- Latin font: `Arial`

Suggested sizes:

- top page label: `20 pt`
- slide title: `30 pt`
- large card text: `27–34 pt`
- answer text: `22–25 pt`

Avoid teaching text below `20 pt` unless the content is a source screenshot.

## Color System

Primary colors:

- ink `#1F2933`
- blue `#2F5597`
- red `#C0392B`
- green `#38761D`
- amber `#F4B183`

Light fills:

- pale blue `#EAF2F8`
- pale red `#FDEDEC`
- pale green `#EAF7EA`
- cream `#FFF7E6`
- white `#FFFFFF`

Usage:

- red: mistake, warning, trap
- green: correct direction, final answer, scoring target
- blue: method, logic, structure
- amber: transition, connector, emphasis

## Header Standard

For inner slides:

- use a dark top bar
- put the page type at left, large and readable
- keep the header clean

Typical page labels:

- 原题
- 避坑
- 方法
- 解题①
- 解题②
- 解题③
- 深度
- 答案

## Layout Standard

Prefer large blocks with consistent spacing.

Use:

- comparison layout for wrong vs right
- three-column layout for methods or progression
- left evidence / right interpretation for solving
- full-width recap band for the final takeaway

Do not add low-value footer text by default.

## Source Screenshot Slides

When the original question matters:

- show the cropped question clearly
- enlarge the useful region
- place it inside a clean framed area
- avoid surrounding it with too much explanatory text

## Default Slide Sequence

Use this sequence unless the task clearly needs a different one:

1. cover / value framing
2. original question
3. low-score trap
4. method overview
5. reasoning layer 1
6. reasoning layer 2
7. reasoning layer 3
8. deeper progression or structure
9. final answer and keywords

## Quality Bar

The deck passes when:

- page labels are readable
- no bottom clutter distracts from the lesson
- visual emphasis matches the teaching logic
- every slide can be understood in a few seconds
- the deck looks intentional rather than autogenerated
